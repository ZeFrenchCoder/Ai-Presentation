### 🛠️ Daily useful prompts

#### Professional email template
```
Write a professional email for [context]. 
Tone: [formal/informal/friendly]
Objective: [request/information/follow-up]
Recipient: [role/relationship]
Key points: [list of elements to include]
```

#### Daily planning
```
Help me plan my day with these tasks:
[task list]

Constraints:
- Available time: [X hours]
- Priorities: [high/medium/low]
- Energy: [morning/afternoon]

Propose an optimized schedule with time slots and justifications.
```

#### Quick synthesis
```
Summarize this text in [X] action-oriented key points:
[text to summarize]

Focus on: [specific aspects if needed]
Audience: [technical/business/general]
```

### 🔄 Daily routine with ChatGPT

#### Morning (10 min)
1. **Day briefing**: "What should I know today about [domain]?"
2. **Prioritization**: "Optimize my to-do list according to these criteria..."
3. **Meeting preparation**: "Relevant questions for the meeting about..."

#### During the day
1. **Contextual help**: Quick prompts according to needs
2. **Reformulation**: Improve communication clarity
3. **Express research**: Quick answers to technical questions

#### Evening (5 min)
1. **Day summary**: "Synthesize my accomplishments"
2. **Tomorrow preparation**: "Prepare my tomorrow's day"
3. **Learning**: "Explain this concept I encountered today"

### 🎯 Efficiency tips

#### Prompt optimization
- **Clear context**: More details = better results
- **Desired format**: Specify expected structure
- **Quick iteration**: Progressively refine
- **Save**: Keep prompts that work

#### Best practices
- **Verification**: Always validate results
- **Personalization**: Adapt to your style and context
- **Balance**: Don't become dependent
- **Learning**: Understand the "why" of suggestions

### 🚀 Progressive evolution

#### Week 1-2: Basics
- Identify 3-5 repetitive tasks
- Test simple prompts
- Create a morning routine

#### Week 3-4: Optimization
- Refine prompts that work
- Add new use cases
- Measure time gains

#### Month 2+: Automation
- Create complete workflows
- Integrate with other tools
- Share best practices with team

## Summary

ChatGPT can transform your daily productivity by assisting your repetitive tasks. The key is to start small, iterate quickly, and progressively build a set of personalized prompts and routines. In a few weeks, you can save several hours per week while improving the quality of your work.
