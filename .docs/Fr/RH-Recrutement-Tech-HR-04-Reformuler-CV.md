# ChatGPT pour reformuler et résumer les CV

**ID:** HR-04  
**Plateforme:** ChatGPT + HR Tools  

## Type d'audience
RH / Recrutement Tech

## AI utilisé
ChatGPT/MS Copilot

## Niveau Connaissance AI
Débutant

## Résumé Technique
Transformer les CV longs en fiches synthétiques orientées compétences.

## Contenu

Téléverser les CV dans un chat sécurisé.

Requête qu’on pourrait demander :

### 1- recommandation

```fdsf
Peux-tu me donner des recommandations ?
```

### 2- Autre branche

```
Selon tout mes experiences, peux-tu me donnée 3 titres que je pourrais effectués.

Me décrire les changements à apporter sur mon CV afin de corresponde le plus proche du mandat
```

### 3- Mandat ciblé

```
Avec le mandat ciblé : <donnée la description>

Me décrire les changements à apporter sur mon CV afin de corresponde le plus proche du mandat

Me lister les formations à effectuer afin de pouvoir être plus pertinant pour le poste

```

### 4- Entrevue Ciblé

```
Voici mon CV et le mandat ciblé.

Peux-tu utilisé de manière interactive (tu me pose une question et je répond).

- Demander 10 questions
- Commenter ma réponce : Pertinance, Bon point, mauvais point. Donnée la réponce recommander. Recommandation et expliquer la raison. 

```
